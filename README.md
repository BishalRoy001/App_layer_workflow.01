# Application Layer Protocol Visualizer

A dual-panel web dashboard that simulates and visualizes application-layer protocols (HTTP, SMTP, DNS, and HTTP Adaptive Streaming) in real time. 

**🟢 Live Demo:** [Click here to test the live application](https://app-layer-workflow-01.onrender.com).

### Features
* **Live DNS Resolution:** Uses Python sockets to resolve real IP addresses.
* **Dual-Panel UI:** Keeps the command center and visualizer synchronized.
* **Playback Controls:** Pause, step, and replay protocol sequences.

### Tech Stack
* Backend: Python & FastAPI
* Frontend: HTML, CSS (Vanilla), JavaScript
* Host: Render
